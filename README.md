Website portofolio Daniel Wicaksana Godjali (nim 18224114)

## Cara publish

1. Push file ini ke repository GitHub Anda.
2. Buka `Settings` -> `Pages` pada repository.
3. Pilih `Source` ke `main` branch dan folder `/ (root)`.
4. Simpan pengaturan.

Setelah beberapa saat, situs akan tersedia di `https://<username>.github.io/<repository>`.

## File utama

- `index.html` — halaman portofolio utama
- `styles.css` — gaya tampilan
- `script.js` — logika menu dan tahun otomatis
